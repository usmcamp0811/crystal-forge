## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Problem: Chips, tags, badges, and count indicators are styled inconsistently across views (staging tags, system counts, environment badges on flakes view, etc.). This creates visual inconsistency and reduces polish.

Goal: Establish a uniform chip/tag/badge design language across all views, using the refined git commit card styling as the reference implementation. Ensure that status indicators, count chips, and categorical tags share a common visual vocabulary.

Reference: The git commit cards in flakes view (post TASK-64) represent the target styling. Use those patterns as the canonical reference for spacing, padding, border-radius, font size, and color treatment.
