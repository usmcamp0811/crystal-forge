### Problem Statement

Need to be able to enforce a deployment policy that a STIG (high, medium, low) is deployed to given systems. 

### Proposed Solution

In order to facilitate an easier way to create deployment policies that enforce STIG compliance. There should be a module system that one could enable a high,medium or low STIG compliance. Could potentially break this out into a bit more fine grain and have modules of modules that give this. 

### Use Case

For managing systems in a restrictive environment such as a DoD environment. 

### Alternatives Considered

We need to do this in a way that will tie attestations about why certain things are disabled with respect to the STIG so that we can easily generate a report for audit time.
