# Data Model

* [Build Queue Status View (`view_build_queue_status`)](view-build-queue-status.md) - Describes view_build_queue_status, the system-level monitoring view of the build queue with package counts, active workers, stale worker detection, cache push lag, example queries, and alert rules.
* [Buildable Derivations View (`view_buildable_derivations`)](view-buildable-derivations.md) - Describes view_buildable_derivations, the system-aware build queue that build workers query to claim packages and NixOS systems, with progress counters, ordering, reservation algorithm, and distributed worker support.
* [Commit Build Status View](view-commit-build-status.md) - Describes view_commit_build_status, which reports per-derivation and per-commit build outcomes (complete, failed, partial, building, no_builds, unknown) for build health and release readiness.
* [Commit Deployment Timeline View](view-commit-deployment-timeline.md) - Describes view_commit_deployment_timeline, the commit-centric 30-day view that approximates deployment time from first system_states entry after a commit, with fields, use cases, and limitations.
* [Config Timeline View (`view_config_timeline`)](view-config-timeline.md) - Describes view_config_timeline, the Grafana config timeline view that labels each commit with the number of systems currently running it, derived from view_system_deployment_status and view_commit_deployment_timeline.
* [Derivation Status Breakdown View](view-derivation-status-breakdown.md) - Describes view_derivation_status_breakdown, which aggregates derivation counts, success and failure distribution, attempts, and durations per derivation status for build health analysis.
* [Flake Recent Commits View (`view_flake_recent_commits`)](view-flake-recent-commits.md) - Describes view_flake_recent_commits, the per-flake snapshot of the last three commits with attempt status (ok, retries, failed/stuck threshold) for Grafana health tables.
* [NixOS Commit Table View (`view_commit_nixos_table`)](view-commit-nixos-table.md) - Describes view_commit_nixos_table, a compact commit-centric table of NixOS derivations with commit-level progress aggregates for Grafana half-width panels.
* [NixOS Derivation Build Queue View (`view_nixos_derivation_build_queue`)](view-nixos-derivation-build-queue.md) - Describes view_nixos_derivation_build_queue, the ordered build queue that places package derivations before their NixOS system derivation for the builder loop and Grafana.
* [System Deployment Status View](view-system-deployment-status.md) - Defines view_system_deployment_status and its up_to_date, behind, no_deployment, unknown, and ahead categories, which compare the observed store path with the newest eligible cache-published NixOS artifact; this is the current deployment status contract.
* [System Heartbeat Status View](view-system-heartbeat-status.md) - Describes view_system_heartbeat_status, the connectivity view that combines the latest agent heartbeat and system state change to classify systems by recent activity.
