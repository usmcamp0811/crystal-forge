# Data Model

* [Build Queue Status View (`view_build_queue_status`)](view-build-queue-status.md) - Describes view_build_queue_status, the SQL view that aggregates package progress, reservation-based worker counts, stale workers, and cache lag per NixOS system for the legacy build-reservation queue, which the server no longer starts; the live build queue is build_jobs.
* [Buildable Derivations View (`view_buildable_derivations`)](view-buildable-derivations.md) - Describes the current view_buildable_derivations definition (migration 0070): unreserved NixOS-system derivations ordered newest commit first, used only by the legacy build-reservation worker that the server no longer starts; the live build queue is build_jobs.
* [Commit Build Status View](view-commit-build-status.md) - Describes view_commit_build_status, which reports per-derivation and per-commit build outcomes (complete, failed, partial, building, no_builds, unknown) for build health and release readiness.
* [Commit Deployment Timeline View](view-commit-deployment-timeline.md) - Describes view_commit_deployment_timeline, the commit-centric 30-day view that approximates deployment time from first system_states entry after a commit, with fields, use cases, and limitations.
* [Config Timeline View (`view_config_timeline`)](view-config-timeline.md) - Describes view_config_timeline, the SQL view that labels each recent commit with the number of systems currently running it, derived from view_system_deployment_status and view_commit_deployment_timeline; its only consumers are the legacy dashboard JSON and the database test suite.
* [Derivation Status Breakdown View](view-derivation-status-breakdown.md) - Describes view_derivation_status_breakdown, which aggregates derivation counts, success and failure distribution, attempts, and durations per derivation status for build health analysis.
* [Flake Recent Commits View (`view_flake_recent_commits`)](view-flake-recent-commits.md) - Describes view_flake_recent_commits, the SQL view of the last three commits per flake with an attempt status derived from the raw commits.attempt_count counter (ok, retries, failed/stuck at 5 or more); its only consumers are the legacy dashboard JSON and the database test suite.
* [NixOS Commit Table View (`view_commit_nixos_table`)](view-commit-nixos-table.md) - Describes view_commit_nixos_table, the SQL view that lists the NixOS derivations of a commit with commit-level progress aggregates; its only consumer is the database test suite.
* [NixOS Derivation Build Queue View (`view_nixos_derivation_build_queue`)](view-nixos-derivation-build-queue.md) - Describes view_nixos_derivation_build_queue, the earliest queue view (migration 0056) that lists package derivations before their NixOS system derivation, newest commit first; nothing in the server reads it, and the live build queue is build_jobs.
* [System Deployment Status View](view-system-deployment-status.md) - Defines view_system_deployment_status and its up_to_date, behind, no_deployment, unknown, and ahead categories, which compare the observed store path with the newest eligible cache-published NixOS artifact; this is the current deployment status contract.
* [System Heartbeat Status View](view-system-heartbeat-status.md) - Describes view_system_heartbeat_status, the connectivity view that combines the latest agent heartbeat and system state change to classify systems by recent activity.
